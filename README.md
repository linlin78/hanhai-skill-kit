# hanhai-skill-kit

一组面向日常项目、网站与内容工作的轻量 Codex Skills。整理：林勇。

## 收录内容

| Skill | 用途 |
| --- | --- |
| `seo-research-toolkit` | 研究关键词、搜索意图与竞品，并输出有优先级的 SEO 机会简报。 |
| `website-launch-auditor` | 在发布前只读审查网站的上线准备、基础 SEO、转化表达与运营风险。 |
| `webapp-testing` | 为网站或 Web 应用设计最小化的功能与回归测试清单。 |
| `simple-video-editing` | 把视频想法、脚本或素材整理成短视频剪辑方案。 |
| `jianying-draft-workflow` | 规划并监督剪映桌面草稿制作；导出前必须获得明确确认。 |

## 使用方式

1. 打开需要处理的项目或资料。
2. 在 Codex 中直接说明任务，并点名所需 Skill，例如：`使用 @website-launch-auditor 审查这个站点，只读，不修改线上环境。`
3. 涉及密钥、账号、付款、正式发布或导出时，按提示由本人完成确认。

## 安全边界

- 本仓库不包含 API Key、Cookie、账号缓存、课程视频或个人资料。
- 不提供自动登录、自动发布、绕过平台限制或无人值守桌面控制。
- 网站审查与测试默认只读；生产写入、真实付款和真实用户数据操作必须另外明确授权。
- 剪映工作流仅处理用户有权使用的本地素材，导出需要本人确认。

## 说明

本仓库只收录本次整理的独立 Skill 文档与必要参考文件；第三方课程、压缩包和外部资料不随仓库分发。
