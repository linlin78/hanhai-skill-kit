# 林勇·剪映草稿自动化

作者：林勇

把用户拥有或获授权的素材整理为剪映桌面版草稿。默认是**安全模式**：生成草稿后停下来，由用户在剪映中预览和导出。

## 先确认模式

- **安全模式（默认）**：生成脚本、素材清单、字幕和草稿方案；导出由用户点击。
- **受控导出模式**：只在用户明确输入“允许导出”后考虑。每次只处理一个已确认的草稿，不发布到任何平台。

不要把“可以生成草稿”说成“已经生成了成片”。没有 Windows 实机验证时，明确说明只能完成方案与环境检查。

## 必要输入

收集目标平台与时长、横/竖屏、口播或脚本、可用素材文件路径、字幕/配音/音乐需求，以及剪映草稿目录。缺少任何一项时，列为待补项，不猜测路径或素材内容。

## 工作流程

1. 检查授权：素材、音乐、图片和人物肖像均由用户拥有或已获许可。
2. 建立剪辑时间轴：镜头、时长、字幕、音频和转场；先粗剪，后装饰。
3. 输出草稿规格：分辨率、帧率、轨道顺序、素材路径、字幕文本与输出目录。
4. 在用户的 Windows 电脑上创建或更新一个**新的**草稿；不得覆盖原草稿。
5. 提示用户打开剪映预览，检查素材丢失、字幕错位、音量和版权信息。
6. 只有收到“允许导出”后才进入受控导出模式；导出完成后报告实际文件路径和结果，不自动上传或发布。

## 受控导出的硬性条件

只有同时满足以下条件才可尝试：

- Windows 桌面环境；剪映专业版已打开；用户已确认当前草稿名称和导出目录。
- 电脑处于空闲状态，用户知晓自动化会占用鼠标和键盘。
- 先做单个短草稿测试；失败即停止，保留原草稿和错误信息。
- 不能关闭程序、删除文件、修改系统设置、登录账号、购买或使用会员权益、绕过弹窗/权限。

不满足时，退回安全模式，并给出用户在剪映中手动导出的步骤。

## 输出格式

始终给出：

1. 状态：方案 / 草稿已创建待预览 / 已获准导出 / 导出完成。
2. 剪辑时间轴表。
3. 草稿和输出的明确路径。
4. 用户下一步只需做的一件事。
5. 风险或缺失项。

## 示例

“使用 $jianying-draft-workflow，根据这个 60 秒口播稿和 `D:\\素材\\产品A` 中的视频生成竖屏剪映草稿方案。先用安全模式，不要导出；把缺少的镜头列出来。”
