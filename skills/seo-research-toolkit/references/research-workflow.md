# SEO research workflow

## 1. Define the question

Record the target keyword, target country/language, product or page type, primary conversion goal, and one to three competitor domains.

## 2. Collect only useful evidence

- Google Trends: relative interest, seasonality, and related queries.
- Google Search: intent, page types, recurring topics, and visible competitors.
- Keyword tools: user-authorized volume, difficulty, and related-keyword data.
- Search Console: user-authorized existing impressions, clicks, pages, and query gaps.
- Similarweb or comparable tools: directional competitor observations only.

## 3. Classify intent

Classify each candidate as informational, commercial investigation, transactional, or navigational. Match the recommendation to the page type needed to satisfy that intent.

## 4. Prioritize

Prioritize a small set of opportunities using intent fit, evidence of demand, relevance to the offer, realistic competition, and implementation effort. State uncertainty instead of inventing numbers.

## 5. Hand off

Deliver the opportunity brief with the recommended page, suggested title/topic angle, evidence, risks, and a clear next action.
